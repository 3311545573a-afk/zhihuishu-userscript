# 学习通 / 智慧树学习助手

**当前版本：v1.2.2**

在 Chrome 或 Edge 中运行的 Tampermonkey 用户脚本，保留学习通课程页功能，并提供智慧树共享课视频、弹题及作业 / 考试页适配。通过右侧面板控制，运行时无需本地服务、Python 或 Node.js。

| 场景 | 功能 | 验证范围 |
| --- | --- | --- |
| 智慧树共享课视频 | 自动发现播放器、自然结束后继续后续未完成视频、跨章及子节切换、最高 1.8 倍速 | 已核查页面结构并通过模拟回归，整节播放和服务器进度保存未完成实页验证 |
| 智慧树共享课弹题 | 文字、公式图片和图文混排的单选、多选、判断，支持分页弹题 | 已核查实际弹题结构，识别、图文请求及作答流程通过模拟回归 |
| 智慧树作业文字题 | 识别单选、多选、判断，自动选择，通过页面“下一题”或“保存”保存答案 | 新版作业页已在 Edge 实测识题、模型请求、选择、保存及按开关提交 |
| 智慧树其他作业 / 考试题 | 填空、简答、图片及图文混排，支持整页多题和逐题翻页 | 已通过模拟回归；考试、填空、简答及真实图片题尚未实页验证 |

AI 答题使用自己的 DeepSeek API Key；视频功能无需 Key。答案由模型生成，可能错误，请核对后提交。

**自动交卷默认关闭，更新时保留已保存的设置。** 验证码需手动完成。题干、图片或作答控件无法完整读取时，脚本会暂停并提示处理。

## 安装与更新

运行环境：**Chrome / Edge + Tampermonkey（篡改猴）**。

1. 安装并启用 Tampermonkey，按浏览器扩展设置开启“允许运行用户脚本”。旧版浏览器的设置方法见 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?q=Q209)。
2. 点击上方“安装最新版脚本”。如果没有出现安装页，可下载 `.user.js`，在 Tampermonkey 管理面板导入；也可新建脚本，用文件全文替换模板并按 `Ctrl+S` 保存。[官方安装说明](https://www.tampermonkey.net/faq.php?q=Q102)
3. 已安装旧版时，**更新原脚本条目**，避免同时启用多个同类脚本。API Key 和开关设置会沿用原配置。
4. **完整刷新课程页或作业答题页**，确认面板显示 **v1.2.2**。新版作业页需要脚本在正常载题请求前运行，只保存脚本后反复点“开始”无法读取已完成的响应。

应安装完整的 `.user.js` 文件；保存的 GitHub `.html` 网页不能作为用户脚本安装。

## 使用方法

### 视频与共享课弹题

进入课程播放页后，面板会自动发现播放器。浏览器阻止自动播放时，先手动点击一次网页播放按钮。面板可控制开始、停止、下一节、倍速及自动跳节；连播以视频自然结束为依据，并尊重手动暂停。

智慧树最高 **1.8 倍速**，旧的超限设置会自动限制并保存；默认“跟随页面”。学习通保留最高 **3 倍速**选项。

需要 AI 弹题作答时，在面板填写自己的 DeepSeek API Key，点击“保存”并开启“自动答题”。脚本会校验题目与页面组件，匹配成功后选择答案并关闭弹题；无法确认时保留人工处理。

### 智慧树作业 / 考试

1. 从平台列表进入具体答题页，保存 API Key。
2. 可先关闭“自动答题”，点击“识别题目”检查题干、选项及图片数量。
3. 开启“自动答题”后，脚本请求模型并填写答案。逐题页面会通过原页面“下一题”保存并切题，末题通过“保存”等待结果。
4. 检查“自动交卷”开关。关闭时填写完成后由你核对提交；主动开启后，脚本按页面流程提交并处理明确的确认窗口。“保存成功”与“提交成功”分别判断。

同页题目按每批最多 8 题、24 张图片请求。停止、关闭自动答题、更换 Key、换题或出现验证码时，旧响应和后续填写会失效，避免将过期答案写入页面。

### 暂停与排查

- 验证码、学习异常和未知弹窗出现时暂停，需在网页手动处理。
- 遇到“检测到异常脚本”，脚本停止本页自动化并释放倍速控制。请停用脚本、关闭当前学习页，再从学堂重新进入。
- “识别题目”可查看识别结果；`Alt+Shift+D` 显示或隐藏面板。
- 长时间无法识题时，先确认版本号和完整刷新，再查看面板日志。反馈问题前请遮盖 Key、姓名、账号及带个人参数的网址。

## 页面兼容说明

智慧树共享课入口为 `studyvideoh5.zhihuishu.com/stuStudy*`。作业 / 考试适配涵盖 `examh5`、`exampc`、`exam` 等答题域及可识别的相关路由，其中包含新版 `onlineexamh5new.zhihuishu.com/stuExamWeb.html`。列表页没有题目，需要先进入答题页。

题目读取支持 Element UI 分组、可分组的原生表单和新版自绘题目结构。同源 iframe 可读取；跨域 iframe、其他特殊封闭编辑器、编码字体，以及未能完整读取的独立附件或复杂子题暂不支持。平台页面版本变化后可能需要重新适配。

新版作业题干使用封闭 Shadow DOM。脚本在页面正常载题时观察官方 `doHomework` / `doExam` 成功响应，仅在当前可见题号、题型、选项 ID 和正文一致时使用题目内容。脚本不重放载题请求，不修改响应、Shadow DOM 模式、验证码或平台检测，也不伪造服务器学习进度。

## 配置与隐私

API Key 优先保存到 Tampermonkey 存储；无 GM 存储时回退到当前页面的 `localStorage`。面板使用密码框显示 Key。请只在自己的浏览器中配置，不要将个人 Key、Cookie、浏览器存储或带账号参数的网址上传到仓库。

| 操作 | 数据去向 |
| --- | --- |
| 开启 AI 答题 | 将题干、选项、图片链接或内嵌图片与 API Key 发送到 `api.deepseek.com/chat/completions` |
| 点击“测试” | 使用 API Key 请求 `api.deepseek.com/models` |
| 新版作业载题观察 | 仅在本页内存缓存匹配所需的题目字段，不保存完整响应、账号或认证字段；页面关闭后丢弃 |
| 学习通备用资源 | 页面缺少 jQuery 时可能从 `code.jquery.com` 加载；字体解码可能读取页面字体资源 |

图片通过 [DeepSeek 图文接口](https://api-docs.deepseek.com/guides/vision/)发送，支持公开 HTTP(S) 图片链接及内嵌 PNG / JPEG / GIF / WebP。需要登录的图片链接、blob 和 SVG 暂不支持。图文输入会产生相应 API 用量，图片读取失败时保留人工处理。

发布文件只包含脚本、测试、依赖清单和说明；测试凭据、题目及课程参数使用模拟数据。本地截图、日志、浏览器数据、开发记录和依赖目录不进入发布文件清单。
