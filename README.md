# 学习通 / 智慧树学习助手（合并适配版）

完整脚本：`dist/xuexitong-zhihuishu.user.js`。源文件为项目根目录同名文件，交付时校验两者一致。

### v1.1.2 更新

支持智慧树弹题中的公式图片：题干、A-D 选项即使全部为无 alt 的图片，也会按原顺序和所属位置构造 DeepSeek 图文请求；文字与图片混排、HTML 上下标也会保留。继续使用现有 Key，无需另配 OCR 服务。

“识别题目”日志会显示图片张数。遇到缺失、不支持的图片或接口读取失败时保持暂停；不同题干/选项图片参与题目签名与组件核对，换图后不会使用旧答案。

已安装旧版时，在 Tampermonkey 中打开原合并脚本，用新版全文替换、Ctrl+S 保存，再刷新课程页；标题应显示 **v1.1.2**。更新原条目即可。

### v1.1.1 更新

修复“页面没有验证码，面板却一直提示人工验证”：腾讯验证码 SDK 会保留全透明、移出屏幕的 iframe；现在仅在验证码 iframe 有实际尺寸、非透明并进入视口时暂停。空的 SDK 容器不再触发提示。

这项验证码修复已包含在当前 v1.1.2 中。

## 环境和安装

运行只需要 **Chrome + Tampermonkey（篡改猴）**，不需要本地服务器、Python、Node.js 或安装任何 npm 包。

1. 在 Chrome 安装并启用 Tampermonkey；打开扩展详情，开启“允许运行用户脚本”。若旧版 Chrome 没有这个开关，按 [Tampermonkey 官方说明](https://www.tampermonkey.net/faq.php?q=Q209) 设置开发者模式。
2. 停用之前的学习通旧脚本，避免同一页面被两份脚本同时控制。
3. 点击 Tampermonkey 图标 → “添加新脚本”。用文本编辑器打开本项目的 `.user.js`，全选复制，替换新脚本编辑器里的全部模板代码，按 **Ctrl+S** 保存。也可在 Tampermonkey 管理面板的实用工具中导入本地文件。[官方安装说明](https://www.tampermonkey.net/faq.php?q=Q102)
4. 刷新智慧树课程播放页。右侧出现“智慧树共享课学习助手”面板后，即可开始或停止。

注意：保存的 GitHub `.html` 网页不能当油猴脚本安装；应安装完整的 `.user.js` 文件。

## 使用

- **视频**：进入共享课播放页后自动发现播放器；若 Chrome 拒绝自动播放，先手动点击一次网页播放按钮。面板可控制开始、停止、下一节、倍速、自动跳节。
- **倍速**：智慧树上限 **1.8 倍**，超出配置会限制到此范围；页面提供的 1.0 / 1.25 / 1.5 / 1.75 倍可选。学习通保留原范围。
- **连播**：自然播放结束后，寻找后续未完成的视频，支持跨章和子节，跳过目录中的章节测试；不会把暂停或临近结尾当作完成。手动暂停会被尊重。
- **DeepSeek 弹题**：面板填入你自己的 API Key 并点“保存”，开启“自动答题”。支持单选、多选、判断，题干和选项可为文字、公式图片或混排，包含同一弹窗的分页题目；仅在题目与网页课程组件一致时自动选项和关闭弹题。没有 Key、关闭开关或组件无法验证时停留供人工处理，识别到的 AI 建议可供核对。
- **验证码、学习异常和未知弹窗**：脚本暂停，需你在网页手动处理；处理完成后按原播放意图恢复。
- **日志与排查**：“识别题目”可查看识别结果；Alt+Shift+D 显示/隐藏面板。组件找不到、目录无法唯一匹配时会停止相应自动操作并提示。

答案由模型生成，可能错误。平台版本变化后如出现“组件无法匹配”，请先手动操作对应任务并保留日志中的错误说明。

## 支持页面与实现

智慧树仅支持 `https://studyvideoh5.zhihuishu.com/stuStudy*` 共享课播放页；保留原脚本的学习通 `mycourse/studentstudy`、`mooc2-ans/mycourse/studentstudy` 路由。智慧树的独立考试页、章节考试不在自动化范围内。

适配按实际网页 Vue2 组件与 DOM 校验，使用其现有的视频切换、答案保存、题目分页和关闭流程；没有伪造服务器进度或修改验证码。智慧树页面对脚本 DOM 点击有检查，因此不盲目模拟选题/关闭点击，也不伪造 `isTrusted`。

API Key 在 Tampermonkey 中通过 GM 存储保存，面板密码框用于输入。开启 AI 时会向 `https://api.deepseek.com/chat/completions` 发送题干、选项、图片地址或内嵌图片以及你的 API Key；“测试”按钮会请求同域模型列表。图片使用 [DeepSeek 官方图文接口](https://api-docs.deepseek.com/guides/vision/)，由其读取公开图片链接；需要登录才能读取的图片链接、blob 和 SVG 图片暂不支持，失败时停留供人工处理。图像输入会产生相应 API 用量。未填写 Key 时视频功能仍可用。原学习通字体解码可能读取页面字体资源，缺少 jQuery 时会从 `code.jquery.com` 加载备用库；智慧树适配无需 jQuery。

继承 [原作者 v1.0.7 脚本](https://github.com/aajddjkfkfke/xuexitong-zidong-shuake-jiaoben/blob/main/xuexitong-deepseek.user.js) 的面板及学习通实现，保留作者署名，原始代码采用 MIT 许可证。当前默认 DeepSeek 模型及接口参数已对照 [官方 API 文档](https://api-docs.deepseek.com/) 核查。

验证范围与最终结果见 `验证结果.md`。已只读核查共享课的隐藏验证码和公式图片弹题结构；尚未完成真实账号下整节视频、进度保存或真实 DeepSeek 图文请求的端到端验证，自动化回归通过不能代替这些实测。

## 配置与隐私

仓库不包含 API Key、Cookie、账号数据或浏览器存储。测试中的 Key、课程参数与图片路径为模拟数据；使用时在 Tampermonkey 面板中填写自己的 Key，不要将个人配置提交到仓库。
